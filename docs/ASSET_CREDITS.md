# Art, authorship and provenance

- `public/art/moon-palace.svg` and `public/art/lotus-garden.svg`: adapted from the user-supplied Claude-made JOSEON design prototype. The project owner is responsible for confirming reuse rights for uploaded materials.
- `public/art/portraits/`: procedurally authored original vector illustrations for this release. Eleven character/NPC designs plus selectable player costume colors; all fictional.
- `public/art/hanseong-map.svg`: original stylized fictional navigation illustration. **Not** a geographically accurate map or scholarly reconstruction.
- Other scene SVGs in `public/art/`: carried forward from the user-supplied JOSEON project.
- UI icons: `lucide-react` (Lucide icons under the ISC license; see https://lucide.dev/license). The application uses CSS and system fonts and does not bundle font binaries.
- Atmosphere: original local Web Audio synthesis; no external soundtrack assets.

Art is used for fictional historical drama. Clothing and court locations are artistic approximations, not museum reconstructions.
